# PPTX 兼容性与验证边界

## 导入与写回

UniPPT 以导入时的原始 OPC 包为基线，保留未编辑部件的字节。编辑后的页面按对象更新。当前可写回文本、表格、形状、图片、OMML 公式和常见动画参数，并支持插入、删除和重排幻灯片。

动画覆盖常见进入、强调、退出效果，点击触发、与上一动画同时、上一动画之后、持续时间、延迟、段落及顺序等参数。尚未建模的高级预设、交互触发器和厂商扩展采用保留优先策略。

## 验证方式

运行 `cargo test --workspace --locked` 检查自包含夹具与回归测试。需要外部文稿的测试标记为 `ignore`，运行前按对应测试的 `UNIPPT_*_CORPUS` 或其他环境变量提供已获使用许可的文件。外部文稿不随源码发行。

验证应分别检查 OPC 部件、content type、relationship、动画时间线、导出后重新导入以及目标 PowerPoint 的渲染。结构或字节检查通过不能单独证明视觉效果相同。

## 仍需专项验证的内容

- 高级动画预设、重复与自动反向、缓动曲线和交互式触发器。
- 切换效果的结构化编辑。
- 原生图表、SmartArt、OLE 与母版的结构化修改。
- 宏、数字签名、IRM 和加密等受保护格式。

复杂文稿应在目标 PowerPoint 版本中检查字体、公式、图表、动画、媒体与导出效果。
