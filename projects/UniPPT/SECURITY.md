# 安全报告

请通过 `cc@omnidoc.top` 私下报告本机文件处理、浏览器边界、MCP 未授权修改、凭据泄露或导出输入验证问题。提供最小复现、受影响版本和预期行为；删除文稿、日志中的个人信息与密钥。

## 本机版边界

- HTTP 服务监听回环地址；本机模型配置只接受回环请求。
- MCP 桥接限制浏览器来源，使用本机客户端令牌和会话凭据。文件内容不能改变授权或系统指令。
- 文稿写入必须检查版本并经过事务验证；超时后先查询结果。
- 用户密钥、浏览器凭据、原始私有文稿、缓存、输出和机器配置不得提交到仓库。
- 格式解析、HTML 导入和本机工具应验证输入与路径，保留资源及执行限制。

公开版不包含账户服务、云存储和协作后端。安全报告请明确本机版的复现步骤。
